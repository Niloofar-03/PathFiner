# PathFinder

A clickable prototype of **PathFinder**, an AI career-path app. Users sync LinkedIn or upload a resume (or answer a short profile quiz), and the app suggests careers, builds a month-by-month roadmap, recommends events and alumni to meet, verifies new skills and tracks readiness for their target role.

> All names, companies, events and numbers in the prototype are sample data.

## Screens

| # | Screen | What it shows |
|---|---|---|
| 00 | Start · Splash | Animated logo and **Start** button |
| 00a | Your background | 7-question profile quiz (status, aim, skills, passions, current field, dream career, what matters), "Other" answers, profile summary |
| 00 | About you · Interests | Dream-career question with Type / Voice answers and accessibility controls |
| 01 | Welcome · Sync | Connect LinkedIn or upload a resume |
| 02 | AI analysis | Resume and LinkedIn analysis progress |
| 03 | Set your timeline | Start date, target role (with "why you fit"), weekly hours |
| 04 | Home | Example profiles (High school, Post-Secondary, Career change), 2-month roadmap, job recommendations |
| 04b | Home · High school | Degree tree, university options, clubs, internships and courses |
| 05 | Career path + alumni | Skills you have vs. skills to build, alumni to connect with |
| 06 | Events | Hackathons, workshops, meetups with Added / Expired status and Add to calendar |
| 07 | Roadmap checklist | Full Nov → May plan with tickable tasks |
| 08 | Event feedback | Log what you did, AI skill verification quiz |
| 09 | Progress | Readiness, skill bars, generate resume |

## Run it locally

Open `index.html` in a browser. No build step or server is needed.

## Publish with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
3. After a minute or two the site is live at `https://<your-username>.github.io/pathfinder-app/`.

Links to a single screen work too, for example `.../pathfinder-app/#/Home`.

## Project structure

```
index.html        App shell: phone frame on desktop, full screen on phones
runtime.js        Small renderer for the design screens (built on Preact)
screens.js        All screens bundled from design/ (generated by build.py)
design/           Original screen designs (.dc.html) and canvas layout
vendor/           Preact 10 (MIT licence)
build.py          Rebuilds screens.js from design/
```

## Updating a screen

1. Replace the matching file in `design/` with the new version.
2. Run `python3 build.py` to regenerate `screens.js`.
3. Commit and push. GitHub Pages redeploys automatically.
